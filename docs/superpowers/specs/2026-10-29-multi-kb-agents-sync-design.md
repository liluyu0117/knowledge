# 多知识库 · 智能体 · 备份同步 设计文档

- 日期：2026-10-29
- 状态：待评审
- 原型：`.dev/mock/kb-agents-proto.html`（交互式，可点击）
- 前置：多知识库后端（kbs.json / 每库独立 Lucene 目录 / kbdata 文档副本）、智能体注册表（agents.json）、问答/检索 kbId 通路**已在本轮早前实现并上线**；本设计覆盖其余部分

## 1. 本设计的范围

1. **UI 重组**：知识库管理独立页（左列表 + 文件夹层级树 + 构建状态列 + 目录选择器）、智能体管理并入问答页（分组 + 新建/编辑）、图标栏新增知识库入口、移除设置页旧的知识库/智能体卡片
2. **会话绑定智能体**：会话记录 agentId，打开会话自动切回并锁定智能体，保证会话永远只搜它对应的知识库
3. **坚果云备份与同步**（WebDAV）：手动/每日自动备份、云端快照恢复、多端同步（拉取/推送）
4. **目录选择器**：后端 `/api/fs/list` + 前端逐级浏览对话框（浏览器无法弹系统目录框）

## 2. UI 重组

### 2.1 图标导航栏
`问答 · 知识库 · 智能体(移除) · 设置 · 调参` → 变为 `问答 · 知识库 · 设置 · 调参`（智能体并入问答页）。

### 2.2 知识库管理页（新路由 /kb）
- **左列表**（248px）：知识库条目（名称徽标、文档数、构建状态 ● 就绪/构建中/失败）、「＋ 新建知识库」按钮
- **右详情**：名称、来源路径 → 工作路径、统计；**文件夹层级树**（目录折叠、文件行含分块数 + 构建状态列：✓ 成功 / ⚠ 失败，悬停 el-tooltip 显示原因）；重建 / 删除按钮
- **新建对话框**：名称 + 本地目录（「浏览…」打开目录选择器）→ 创建后端复制文件到 `kbdata/{id}/` → 自动构建（含向量，护栏生效）

### 2.3 目录选择器
- 后端 `GET /api/fs/list?path=`：path 为空返回盘符列表（`File.listRoots()`），否则返回该目录下的**子目录**（不含文件）
- 前端对话框：面包屑当前位置 + 子目录列表 + 「返回上级」+「选择当前目录」回填输入框
- 安全：后端校验 path 为绝对路径且存在

### 2.3.1 笔记（独立功能）
- 图标导航栏新增「📝 笔记」独立入口；页面 = 左侧笔记列表（标题/类型/时间，＋新建）+ 右侧编辑器（标题输入 / 类型分段 md·txt·doc / 内容 textarea / 保存 / 删除）
- 存储：`.kb/notes/{id}.{md|txt|docx}` + `notes.json` 注册表，**独立于知识库**
- doc 类型保存时由 POI XWPF 生成 .docx；md/txt 原样写入
- 编辑器自动保存（防丢）；后续版本支持「推送到知识库」把笔记转为某库文档参与检索（v1 不做，UI 预留提示）

### 2.4 智能体并入问答页
- 侧栏顶部：`[＋ 新会话] [🤖 新建智能体]` 两按钮
- 会话按智能体分组：组头（头像色块 + 智能体名 + 会话数 + 悬停 ✎ 编辑）；组内会话按时间倒序
- 新建/编辑智能体 = `el-dialog`（名称 / 头像色 / 描述 / 厂商 el-select / 模型 / **系统提示词 el-input textarea** / 知识库 el-select）
- **系统提示词**：RAG 时替换默认系统提示的第一段（"你是{名称}，{描述}。{系统提示词}" + 检索规则段固定拼接）——智能体的角色定制核心，对齐 Cherry 的助手设计
- **描述 + 头像色**：色板 8 色（创建时轮转取色），用于侧栏分组色点与智能体卡片头像
- 删除智能体：其会话保留并归入"默认助手"组（不级联删除会话）
- 设置页旧的知识库/智能体卡片移除（知识库管理走独立页）
- **回答不佳引导**：回答为空/错误/用户标记"不满意"时，卡片底部显示「去检索测试页排查是检索层还是回答层」的引导链接
- **AI 生成系统提示词**：对话框内「✨ AI 生成」按钮——把名称/描述/绑定知识库的文档标题样本交给当前厂商模型，生成一份贴合角色的系统提示词草稿填入输入框，用户可再编辑；接口 `POST /api/agents/gen-prompt`（非流式，失败 toast 提示）

### 2.5 设置页保留内容
厂商配置、索引与数据源（只服务默认知识库）、备份与同步（新）、MCP、评估入口在检索测试页。

## 3. 会话绑定智能体

- `chat.db` 的 session 表加 `agent_id TEXT`（ALTER TABLE 兼容旧库，旧行为 NULL = 默认）
- 会话创建时记录当前 agentId；**打开会话时前端自动把智能体选择器切回该值并置灰锁定**
- 后端 `/api/ask` 以请求里的 agentId + 会话的 agent_id 双重校验，不一致时以**会话的 agent_id** 为准（保证不串库）
- 侧栏按 agentId 分组渲染；无 agentId 的旧会话归入"默认助手"组

## 4. 坚果云备份与同步

### 4.1 WebDAV 客户端
`kbapp/sync/WebDavClient.java`：基于 Java 11 HttpClient 实现 `PUT / GET / PROPFIND(深度1) / MKCOL`。配置：服务器地址（默认 `https://dav.jianguoyun.com/dav/`）、账号、应用密码（存 `.kb/app.json` 的 `sync` 节）。连通测试 = 对备份目录发 PROPFIND。

### 4.2 备份
- 打包内容：`kbdata/`（知识库文档副本）、`chat.db`、`kbs.json`、`agents.json`、`app.json`（脱敏：**不含 API Key**）、`eval.json`；**不含 lucene/ 索引**（可由文档副本重建）
- 产物：`backup-{yyyyMMdd-HHmm}.zip`，PUT 到 `备份目录/kb-backup/`
- 触发：设置页「立即备份」；每日自动（固定本地时间，`@Scheduled`）
- 保留策略：云端保留最近 10 份，超出删最旧

### 4.3 恢复
- PROPFIND 列出云端备份 → 用户选择 → 下载解压 → 覆盖本地对应文件 → 提示重启后端（或自动热重载注册表）
- 恢复后 Lucene 索引清空由后台增量重建（向量按需重嵌，已有 hash 对账）

### 4.4 多端同步
- 模型：**快照式，后写胜出**（明确不支持会话级合并——单用户场景可接受）
- 云端维护 `sync-state.json`：{lastPushAt, deviceId, summary}
- 本机启动时 PROPFIND 比对：云端比本机新 → 提示「拉取云端数据」；本机比云端新 → 提示「推送」
- 拉取 = 恢复流程 + 本地索引自动重建；推送 = 备份流程复用
- 设备标识：首次生成 deviceId 存本地，用于快照摘要展示（"另一台设备 xxx 推送"）

### 4.5 接口
| 方法 | 路径 | 说明 |
|---|---|---|
| GET/PUT | /api/sync/config | 读写 WebDAV 配置 |
| GET | /api/sync/test | 连通测试 |
| POST | /api/sync/backup | 立即备份 |
| GET | /api/sync/list | 云端备份列表 |
| POST | /api/sync/restore | 恢复指定备份 |
| GET | /api/sync/status | 云端/本地版本比对状态 |
| POST | /api/agents/gen-prompt | AI 生成智能体系统提示词草稿 |

## 5. 错误处理

- WebDAV 认证失败 / 网络超时：toast 明确提示，自动备份失败静默重试一次后记入日志
- 恢复前强制本地先做一次"安全备份"（backup-pre-restore.zip），防误覆盖
- 目录选择器：拒绝选择不存在的路径；复制源目录为空时提示
- 删除知识库二次确认；默认知识库不可删

## 6. 明确不做

会话级合并（多端同时新增会话的合并）、双向实时同步、除坚果云外的 WebDAV 服务商适配（协议通用，配置化后天然支持，但只对坚果云做测试）、加密备份。

## 7. 实现顺序建议

1. 会话绑定智能体（小，独立）
2. UI 重组（知识库页 + 目录选择器 + 智能体并入问答页）
3. WebDAV 备份/恢复/同步
